Hard limitations

Do not hide
  • Only a narrow MVP subset of source, configuration and certificate formats is scanned.
  • A stack profile does not replace direct probing when build, provider or application configuration differs.
  • Phase 0 stack-reuse savings are simulation results, not guaranteed enterprise savings.
  • The MVP does not claim an enterprise is “quantum-safe”, “secure” or “production-ready”.
  • Public Web PKI, HSM/KMS firmware and vendor appliances remain external dependencies.
  • ML-DSA certificate transition is a controlled lab demonstration, not a browser-ecosystem claim.
